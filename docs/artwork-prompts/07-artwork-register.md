# 07 – Artwork-Register

Dieses Register ist die zentrale Liste für geplante und umgesetzte Artworks. Statuswerte: **Geplant**, **In Arbeit**, **Review**, **Freigegeben**, **Im Spiel integriert**.

**Lesart:** „In Arbeit" mit dem Zusatz *(Greybox)* heißt, dass nur eine einfache Platzhalterform im Spiel ist. „Im Spiel integriert" wird nur gesetzt, wenn Fabrik, Registrierung, Platzierung und Sichtprüfung in der laufenden Szene vorliegen. Das ist eine technische Aussage; die Sichtprüfung ist die Prüfung in der laufenden Szene in Headless-Chromium mit Software-Rendering (Browserprüfung mit Screenshots), nicht eine Prüfung auf echter Grafikhardware; eine gestalterische Freigabe („Freigegeben") erteilt der Projektinhaber.
